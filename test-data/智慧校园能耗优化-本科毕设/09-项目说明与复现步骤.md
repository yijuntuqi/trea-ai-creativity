# 基于时空图神经网络与边缘计算的校园楼宇能耗优化系统

> 本科毕业设计 · 林晓（2022210318） · 指导教师 王建国 教授

## 1. 项目简介

本项目采集校园 12 栋楼宇 15 分钟粒度的用电、气象与课表数据，构建时空图神经网络（STGNN）完成未来 24 小时负荷预测，并将蒸馏量化后的模型部署到边缘网关，输出楼宇间负荷迁移建议。试运行 6 周实现削峰 11.6%。

## 2. 目录结构

```
campus-energy/
├── data/                 # 清洗后的 parquet 与数据字典
├── src/
│   ├── dataset.py        # 图结构构建与滑窗采样
│   ├── model_stgnn.py    # 图卷积 + TCN + 注意力
│   ├── train.py          # 云端训练脚本
│   ├── distill.py        # 知识蒸馏与 INT8 量化
│   └── scheduler.py      # 负荷迁移规则
├── edge/                 # 网关侧 FastAPI 服务
├── configs/              # 训练与部署配置
└── reports/              # 实验记录与图表
```

## 3. 环境与复现步骤

1. 安装依赖：`pip install -r requirements.txt`（PyTorch 2.3、numpy、pandas、scikit-learn、tensorrt）。
2. 数据准备：将原始电表数据放入 `data/raw/`，执行 `python src/dataset.py --build`。
3. 训练：`python src/train.py --config configs/stgnn.yaml`，单卡 RTX 4090 约 92 分钟。
4. 蒸馏与量化：`python src/distill.py --teacher runs/best.pt --out runs/student_int8.trt`。
5. 边缘部署：将 `runs/student_int8.trt` 拷贝至网关 `/opt/energy/`，执行 `systemctl restart energy-gateway`。
6. 前端看板：`cd web && npm install && npm run dev`。

## 5. 已知问题

- 目前只在一个校区完成验证，跨校区迁移需要重新标定图结构与变压器容量。
- 极端天气样本不足，寒潮与连续高温叠加场景的误差仍有波动。
- 蒸馏带来约 1.2% 的 MAE 损失，精度敏感场景需要重新权衡。

## 6. 数据说明

本仓库内数据为答辩演示用脱敏/虚构数据，电表读数在原始量级上做了比例缩放，不影响方法复现。
