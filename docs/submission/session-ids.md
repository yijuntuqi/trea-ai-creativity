## 如何查询自己的 TRAE 会话历史

1. 打开 TRAE IDE 左侧边栏的 **Chat** 面板。
2. 点击右上角的 **历史记录** 图标（时钟形状）。
3. 每一条历史记录就是一个会话，双击任务标题可复制 Session ID。
