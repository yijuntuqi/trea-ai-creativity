## 如何查询自己的 TRAE 会话历史

1. 打开 TRAE IDE 左侧边栏的 **Chat** 面板。
2. 点击右上角的 **历史记录** 图标（时钟形状）。
3. 每一条历史记录就是一个会话，点击可以重新打开。
4. 打开后从地址栏或页面信息中复制会话 ID（通常是一个 32 位左右的十六进制字符串）。
5. 每个"新对话"按钮对应一个新的 Session ID。
