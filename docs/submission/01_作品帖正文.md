## 一、个人介绍

大家好，我是【待填：姓名 / 昵称】，【待填：学校 + 专业 + 年级】。平时喜欢把身边的小麻烦做成能用的工具，这个项目是我第一次完整地用 TRAE 从 0 到 1 做完一个真正上线、能被别人使用的产品。

**创作起点**：大二下学期的开题答辩，我准备了整整两周，把 PPT 背得很熟，结果现场被老师一句「你这个创新点和已有的 XX 方案有什么区别」问住，之后的三分钟基本在硬撑。下来后我意识到，我缺的不是材料，而是**有人提前用评委的视角问我一遍**。找师兄师姐模拟一次成本太高，看经验帖又只能看到别人的问题。我当时想：如果有个东西能在我上台前，用三个不同性格的评委把我的材料反复问穿，那该多好。

**第一个用户**：是我同组做毕设的同学。他原来的做法是把论文摘要发给我，让我随便问几个问题——问了七八个就卡住了，因为我也不是他领域的。现在他用这个工具，把开题报告传进去，跑完一场拿到报告，回头改了两处证据不足的地方，第二次模拟分数从 62 涨到 78。

**如果没有这个作品**：他还是会找我，或者干脆不模拟，直接上台赌一把。答辩只有一次机会，这种「赌」的成本其实很高。

## 二、产品简介

**是什么**：答辩预演官是一个网页应用（Web App）。上传论文、开题报告或 PPT 大纲，三位不同风格的 AI 评委轮流追问，结束后自动生成四维评分、逐题点评、参考话术与复盘清单。

**面向谁**：需要做开题、中期、毕业答辩的本科生与研究生，尤其是「材料写完了但不知道怎么被问」的同学。典型场景是答辩前 3–7 天，用 15 分钟跑一场模拟，按报告改材料。

**核心功能与使用路径**：

1. **建场**：选择答辩类型（开题 / 中期 / 毕业 / 自定义）、学科、严格度、目标题量与限时，可自选参与评委。
2. **上传材料**：支持 PDF、PPTX、Word、Excel、Markdown、JSON、CSV、TXT 多文件同时上传，也可直接粘贴文本。**文件只在浏览器内解析，原文不上传**。
3. **材料画像**：自动提炼「研究问题—方法—创新点—关键证据—局限—关键词」，让你先看清评委能抓住什么。
4. **多评委追问**：方法论派、创新性质疑派、应用价值派按顺序轮换提问，支持最多两层追问；可随时请求提示、跳过当前题。
5. **复盘报告**：四维评分（内容准确性 / 逻辑结构 / 应答深度 / 表达清晰）、高危问题 Top 5、逐题点评与可照读的参考话术、可执行的复盘清单。
6. **导出与沉淀**：报告支持 PNG / JPG / PDF / Word / Markdown 导出（默认展开全部逐题点评）；历史记录可回看、「再练一场」，登录后自动云端同步。

## 五、TRAE 实践过程

这个项目从 0 到 1 全部在 TRAE 里完成，几个关键阶段：

1. **立意与需求**：用 TRAE 把「答辩准备缺真实追问」拆成可执行的需求与设计文档，先定数据模型和评分规则，再动代码。
2. **主流程开发**：建场 → 材料解析 → 画像 → 提问 → 点评 → 报告，逐块实现并配套 Vitest 测试（当前 110 个用例）。
3. **真实联调踩坑**：上线后点评突然全变成模板文案，排查发现是模型默认开启「思考模式」，单次调用 40 秒以上，超过 Netlify 函数超时，被降级成 mock。关掉思考模式后降到 5–8 秒，问题消失——这个坑让我第一次真正理解「流式 + 超时」的边界。
4. **第二版整改**：接入 Supabase 账号与云端同步、报告多格式导出、历史记录「再练一场」、免费/VIP 权益与 GitHub 仓库导入。

- **超时不是玄学**：把「模型思考模式」和「Serverless 空闲超时」放在一起看，问题一次说清。
