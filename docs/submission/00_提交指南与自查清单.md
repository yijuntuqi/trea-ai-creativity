## 二、发帖步骤

1. 打开 [比赛专区](https://forum.trae.cn/c/45-category/45)，点「新建话题」。
2. 标签选 **学习科研**（必须与报名赛道一致）。
3. 标题：`学习科研｜答辩预演官 —— AI 三评委答辩模拟与复盘报告`。
4. 正文：把 `01_作品帖正文.md` 的内容整段粘贴进去，把 `【待填】` 全部替换成真实信息。
5. 在图片位置依次上传 `04_产品截图` 里的截图（建议 5 张）。
6. 提交前对照下面第三节自查。

## 三、提交前自查清单

### 硬性要求

- [ ] 标签 = 学习科研（与报名赛道一致）
- [ ] 标题含赛道 + 作品名
- [ ] 正文 5 部分齐全：个人介绍、产品简介、体验地址、演示视频、TRAE 实践过程
- [ ] 体验链接公开可访问（换一台设备 / 无痕窗口验证）
- [ ] 核心功能可运行：能建场、能上传、能出题、能出报告
- [ ] 截图 ≥3 张（本目录已有 10 张）
- [ ] Session ID ≥3 个（`03` 里已列 3 个，其中 1 个待你补当前会话）
- [ ] 演示视频 1–5 分钟，公开可访问

### 内容质量

- [ ] 个人介绍写的是真实、具体的故事（不要写「很多同学都有这个问题」）
- [ ] 产品简介里说清了「是什么 / 面向谁 / 有什么功能」
- [ ] 截图里没有个人隐私（真实姓名、学号、导师姓名）
- [ ] 截图里没有「演示模式」角标（有的话说明当时模型没连上）
- [ ] 没有出现「付费购买」引导：作品默认演示模式，会员页不展示真实收款码

### 账号与资格

- [ ] TRAE 账号与社区账号用同一手机号
- [ ] 已完成学生认证并领取学生积分
- [ ] 作品帖发布在「TRAE 大学生创造力大赛专区」，不是其他版块

## 五、时间安排建议

- 现在 → 12 月上旬：补个人介绍与 Session ID、录演示视频、发帖
- 发帖后：把帖子链接发给熟悉的同学/老师点开体验一次（真实访问量不影响评分，但能帮你发现体验问题）
- 12 月中下旬：按社区反馈修小问题，保持体验链接可用
- 截止：**2026 年 12 月 25 日前必须完成发帖**，逾期不能进入评审

## 六、常见坑

1. **体验链接只是「个人可见」**：部署平台可能有访问密码或团队权限，务必用无痕窗口确认。
2. **Session ID 复制错**：要复制对话任务的 ID，不是帖子 ID、不是 commit hash。
3. **截图暴露隐私**：上传前看一眼有没有真实姓名、学校、导师名字。
4. **视频设成私密**：评审打不开等于没交。
5. **帖子里出现真实收款码**：作品默认演示模式即是为了避免这个，别在截图里露出。
