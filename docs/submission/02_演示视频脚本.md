# 演示视频脚本（2 分钟录屏）

> 目标：让评审在 2 分钟内看懂「解决什么问题、怎么用、效果如何」。
> 录制建议：Chrome 全屏录屏（或 Windows 自带 Xbox Game Bar / OBS），1440×900 以上分辨率，麦克风环境安静；鼠标移动放慢，点击前停 0.5 秒。
> 剪辑建议：不要求专业剪辑，但建议加 3–4 个字幕条（见下方「字幕卡」）。

## 分镜表

| 时间 | 画面操作 | 口播稿 |
| --- | --- | --- |
| 0:00–0:12 | 停在首页，缓慢滚动一屏 | 开题答辩最怕的不是材料写不好，而是没人提前用评委的视角问你一遍。这是我的作品——答辩预演官。 |
| 0:12–0:30 | 点「开始预演」，在建场页选「开题 / 理工 / 标准」，把目标题量改成 3，展示底部实时摘要 | 先设定这场答辩：类型、学科、严格度、题量、限时，还可以自选评委。三秒钟建好一场，跟真实答辩一样的配置。 |
| 0:30–0:55 | 进入上传页，粘贴一段论文摘要（或上传 PDF），点击「解析并生成画像」 | 把论文、开题报告或者 PPT 大纲传进来。文件只在浏览器里解析，原文不会上传，这点对没公开的论文很重要。 |
| 0:55–1:12 | 画像生成完成，鼠标依次划过高亮「研究问题 / 方法 / 创新点 / 证据 / 局限」 | 系统会先把材料拆成这五块。这其实就是在告诉评委：你能被问的地方在这里。 |
| 1:12–1:35 | 点「开始答辩」，输入一段回答并提交，展示点评卡片（分数、缺口、参考话术） | 三位性格不同的评委轮流追问：方法论派抠细节，创新性质疑派比差异，应用价值派问落地。每一题都给分、给具体缺口，还给一段可以照读的参考话术。 |
| 1:35–1:52 | 点「结束并出报告」，展示总分、四维雷达图、高危问题 Top 5 | 结束之后不是一句「还不错」，而是四维评分、高危问题 Top 5，和一份可执行的复盘清单。 |
| 1:52–2:05 | 点「格式」选择 PDF，点「保存报告」，展示导出结果 | 报告能导出成图片、PDF、Word，默认展开全部逐题点评，直接发给导师看。 |
| 2:05–2:15 | 回到历史记录，展示列表与「再练一场」 | 每一场都留着，可以接着练，也能换材料重来一遍。 |

## 字幕卡（可选，加在关键节点）

1. `0:12` — 15 秒建一场，配置跟真实答辩一致
2. `0:30` — 材料只在浏览器内解析，原文不上传
3. `1:12` — 三评委轮流追问，支持两层反问
4. `1:35` — 四维评分 + 高危问题 + 可照读话术
5. `1:52` — 一键导出 PDF / Word，直接给导师

## 录制前检查

- [ ] 用未登录的无痕窗口录制（避免露出个人账号信息）
- [ ] 提前跑通一遍流程，确认网络正常、模型响应在 10 秒内
- [ ] 材料准备一段 300–500 字的真实论文摘要，不要用空白模板
- [ ] 报告中若有真实姓名/学校，先替换掉
- [ ] 录完检查：全程无报错弹窗、无「演示模式」提示（说明模型调用正常）

## 上传渠道

- B 站 / 抖音公开视频，标题含「TRAE AI 全国大学生创造力大赛」便于检索
- 视频设为「公开」，不要设「仅自己可见」，否则评审打不开
